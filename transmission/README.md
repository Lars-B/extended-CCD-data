# Measles transmission data

This folder contains data and scripts related to **[measles outbreak data]**.  

## Contents

- `data/` — Raw or processed data files (mostly tree files).
- `scripts/` — Analysis or processing scripts.
- `plots/` — Figures that were generated

## Source Data

The data in this folder was obtained from the following repository:

	- [CDC/Measles-Case-and-Genetic-Metadata](https://data.cdc.gov/Models/Measles-Case-and-Genetic-Metadata-Operation-Allies/b8tp-jsmh)


## Reference

If you use this data in your work, please cite the following publication:

> Masters, Nina B., et al. 2023. *"Measles virus transmission patterns and public health responses during Operation Allies Welcome: a descriptive epidemiological study."*. The Lancet Public Health 8.8 (2023): e618-e628. [10.1016/S2468-2667(23)00130-5](https://doi.org/10.1016/S2468-2667(23)00130-5)
