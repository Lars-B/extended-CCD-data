# Phylogeography data

This folder contains data and scripts related to **[phylogeography Covid dataset]**.  

## Contents

- `data/` — Raw or processed data files (mostly tree files).
- `scripts/` — Analysis or processing scripts.
- `plots/` — Figures that were generated

## Source Data

The data in this folder was obtained from the following repository:  
[SarahNadeau/cov-europe-bdmm](https://github.com/SarahNadeau/cov-europe-bdmm).

Specifically we have used the posterior trees file from `analyses/with_hubei_migration_decrease/processed_results.tar.gz`.

## Reference

If you use this data in your work, please cite the following publication:

> Nadeau, Sarah A., et al. 2021. *"The origin and early spread of SARS-CoV-2 in Europe."*. Proceedings of the National Academy of Sciences 118.9 (2021): e2012008118.. [10.1073/pnas.2012008118](https://doi.org/10.1073/pnas.2012008118)
